# Aryan Game

Mobile-first, installable web-game prototype with Phases 1–4.

The first demo will include a playable Phase 1 arena, team selection, Phase 2 enhancement interface, Phase 3 mission placeholder, and Phase 4 hostel character schedules. Unspecified mechanics will be marked as work in progress.

Development repository for the Aryan Game project. Hosted previews will use Vercel, not Replit.
